# SKILL: DEFINITION OF DONE (DoD)
1. CRITERIO BINARIO DE CONCLUSAO:
- "Esforco nao e conclusao". Uma tarefa so esta PRONTA quando:
  * O dado factual responder diretamente a duvida do operador (sem placeholders).
  * O comando executado retornar codigo 0 e dados uteis.
2. PROIBICAO DE FALHA PREMATURA:
- Se o resultado da ferramenta for vazio ou nulo, e PROIBIDO responder "nao encontrei" sem antes executar 1 tentativa alternativa.
